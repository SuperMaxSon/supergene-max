이 시연을 읽는 법

탱크의 층은 메모리 종류별 몫이고, 오른쪽 목록이 같은 값을 그림과 함께 보여 준다. 재생 중 1MB 넘게 바뀌면 그 종류 그림이 폰 → 탱크(올림) 또는 탱크 → 밖(내림)으로 날아간다. 타임라인 아래 띠는 그때 떠 있던 화면(부팅 · 마을 · 인게임 · 채팅)이고, 점선은 「겹치기」를 켰을 때 바로 앞 버전의 합이다. 버전마다 봇 경로가 달라 채팅 시점은 서로 어긋난다.
숫자는 봇이 WebGL 호출을 직접 세서 낸 GPU 텍스처 합이다. 에셋 크기(가로×세로×4)만 더하면 동적 아틀라스와 라벨이 빠져 절반만 보인다. 프리뷰라 텍스처 압축 전 값이고, 10-16 FB 웹 빌드 로그도 압축이 들어가기 전이라 같은 수준(첫 채팅 107 · 인게임 102 · 피크 138MB)으로 나왔다.
봇은 사람보다 채팅을 빨리 넘긴다. 그래서 채팅마다 오르내리는 톱니 간격이 실제보다 촘촘하다.

시연 아래 띠는 10초마다 묶었다. MB 띠는 부팅이 커서 제곱근 눈금이다. 띠를 누르면 그 구간 비용이 다운로드 탱크 옆에 나온다.

이 표를 읽는 법

채팅 오르내림 = 채팅마다 채팅 몫이 바닥에서 얼마나 올라갔다 내려오는지의 평균(첫 채팅 제외). 스위칭 때 튀는 양이 이것이다. 마을 · 인게임은 그 구간의 시간 가중 중앙값, 피크는 판 최대 순간이다. 작은 숫자는 바로 앞 버전 대비 증감.
봇 플레이는 판마다 경로(심부름 속도 · 채팅 시점)가 달라 같은 코드도 몇 MB 흔들린다 — 몇 MB 차이는 흔들림일 수 있다.
버전마다 클라 판본 · 봇 판본+패치 · RU 시작 저장본을 남겨 둔다. 「vN 으로 다시 돌려줘」 하면 그 버전 그대로 다시 잰다.
