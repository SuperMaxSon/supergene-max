스토리 머지 — 앞으로 해야 할 것

만들 것은 데코 + 채팅 + 머지2, 지금 있는 것은 연출 검증 프로토입니다. 레퍼런스 Gossip Harbor 대비로 남은 거리를 재고, 3개월 스코프로 잘랐습니다. 결론 한 줄 — 부족한 건 파트가 아니라 파트를 잇는 순환입니다.

끊긴 루프 레퍼런스 5레이어 위에 우리 현재를 얹었다

그림 읽는 법

박스는 레퍼런스의 레이어, 배지는 우리 현재. L5만 살아 있고 허브인 L3이 비어서 PopupTask → 1머지 → 복귀가 루프가 아니라 연출 사이 삽입물로 동작합니다.

파트별 완성도 연출은 앞서 있고 구조가 비었다

% 는 감각치, 막대 옆 문구가 실측

잘 만든 연출이 11노드 하드코딩 검증 위에 얹혀 있어 한 챕터만 늘려도 막힙니다.

갭 17개 연결성으로 갈랐다 — 재미 크기가 아니다

# 시스템 현재 → 3개월 목표 판정
G1아이템 체인 티어 3 · 데이터 없음 → 체인 6~8종 필수
G2생성기 1개 무한 → 다중 + 충전/쿨다운 필수
G3에너지 없음 → 시간회복 단순판 필수
G4오더 없음 → 주문 큐 + 제출 20~30개 필수
G5재화 · 레벨 coin = 0 → 코인 + 경험치 필수
G6데코레이션 없음 → 방 1~2개 + 진행도 필수
G7스토리 구조 선형 11노드 → 챕터 2~3개 + 언락 필수
G8세이브 없음 → 로컬 + FB 스토리지 필수
G9보드 상태 저장 매번 새 보드 → 그대로 유지 필수
G17튜토리얼 스토리 노드 1개가 대신 → 최소 시스템 필수
G10인벤토리 · 버블없음 → 보류 후순위
G11잠금 · 자물쇠없음 → 보류 후순위
G16로컬라이제이션text_en 단일 → 구조만 후순위
G12이벤트 보드없음 → 안 만든다 컷
G13시즌패스 · 상점 · 과금없음 → 인터페이스 훅만 컷
G14스토리 분기없음 → 데이터 컬럼만 예약 컷
G15소셜 · 친구플랫폼 SDK만 → 안 만든다 컷
컷이라도 자리는 비워둔다

그래서 화려하지 않은 G9 보드 저장이 필수에, 매출에 직결되는 G12 이벤트 보드가 컷에 갑니다. 훅과 데이터 컬럼을 지금 안 뚫어두면 나중에 세이브 스키마 마이그레이션이 한 번 더 생깁니다.
