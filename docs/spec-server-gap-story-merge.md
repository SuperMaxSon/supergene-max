## 할 일
항목 ID마다 어느 쪽으로 맞출지 정한다: **기획서**(서버를 고침) · **프로토콜**(기획서를 고침) · **둘 다 수정** · **보류**(누가 무엇을 정해야 하는지). SP- 항목은 기획서 안의 두 문장 A·B 중 맞는 쪽을 고른다. 기획서 결정 기록이 있으면 근거로 쓰고, 근거 없이 추측하지 않는다.

## 답변 형식 (항목마다 한 줄)
```
ID | 결정(기획서/프로토콜/둘 다 수정/보류) | 근거(기획서 절·결정 기록) | 고칠 문서와 고칠 내용 한 줄
```
