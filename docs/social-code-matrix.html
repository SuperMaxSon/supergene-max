솔리테어 리포의 FacebookPlatform.ts·공유/초대/토너 호출부, 소셜 슬롯과 게이트 로직, 그리고 3400·3500·3600·3050~3052·3130 로그 스펙 — 이 중 하나라도 바뀌면 해당 줄을 그 자리에서 고칩니다.
벤치 4종(코지·퍼블마·마종·코인매치)은 상시 추적하지 않습니다. 벤치 리포를 다시 실측했을 때만 그 열을 갱신하고, 실측 시점을 .doc-meta에 다시 적습니다.
성공률·유저일당이 움직이는 것은 이 문서의 갱신 사유가 아닙니다 — 그건 조사 문서와 주간 KPI 쪽입니다.
