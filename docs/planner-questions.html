위쪽은 아직 답이 필요한 질문만, 맨 아래 답변 완료 섹션에 답이 온 질문을 모았습니다. 공통 질문은 여러 화면에 같이 걸린 것이라 한 번 정해 주시면 같이 풀립니다 — 먼저 보시면 좋습니다. 그 아래는 화면별로 접어 두었고, 화면 이름을 누르면 질문 표가 펼쳐집니다. 기획 메모는 답 대신 남겨 주신 미결 이유입니다. 화면 이름 옆 「구현됨 · 구현 전」은 화면 개발 상태이고 질문 상태가 아닙니다. 답변 완료는 이미 답을 주셨고 기획서 · 시트 반영만 남은 것입니다 — 답에 조건을 붙여 주신 것은 노란 단서 줄로 따로 띄웠습니다. 답이 정해질 때까지 클라이언트는 지금 동작을 그대로 둡니다.

어디서 나왔나

뷰·팝업 구현 현황의 「필요한 기획」과 같은 목록입니다. 화면 요소표를 행마다 대조했고, 「원문 근거 · 찾아본 곳」이 붙은 질문은 웹 원문 전문 검색으로 「기획서에 없다」를 판정한 것이고, 원문 대조 전 표시가 붙은 27건은 요소표 대조까지만 했습니다(원문에 답이 있으면 알려 주세요). 원문에 답이 있던 것 · 런칭 OFF · 범위 밖은 뺐고, 클라이언트가 일부러 기획과 다르게 가기로 한 1건도 질문에서 뺐습니다. 서버 쪽 결정(API · 저장 필드 · 프로토콜 · 서버 시각 · 결제 검증 · 오류 번호 목록 등) 21건은 서버와 따로 정할 것이라 이 보관함에서 뺐습니다 — 클라이언트 · 개발이 기본값으로 정해 갈 것(표기 형식 · 배치 · 연출 시간 · 탭 이동처 · 문구 키 · 저장 필드 등) 309건도 뺐습니다 — 화면을 만드는 데 기획에서 정해 주셔야 할 것만 남겼습니다. 질문 번호는 한 번 붙으면 바뀌지 않습니다.
