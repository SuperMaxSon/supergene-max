토너먼트 참가 · 전환 다이얼로그 1회 — QA 가이드

토너먼트 목록에서 참가하는 흐름을 고쳤습니다. ① 참가를 누를 때는 다이얼로그가 뜨지 않고 프리게임 팝업으로 바로 갑니다 — 전환 다이얼로그는 Play를 누를 때 딱 한 번입니다. ② 참가할 수 없는 토너먼트는 목록에 아예 나오지 않습니다. 중요한 전제: 수정 전에는 목록에서 참가가 한 번도 성공하지 않았습니다 — 이번에 처음 동작하는 기능이라 점수·공유까지 이어지는 C 섹션이 핵심입니다.

솔리테어 · FB 인스턴트 prod 빌드 필수 친구 계정 2개 필요 클라 코드 실측 + 실기 로그 확인 2026-08-13

변경점

"플로우만 바뀐 것"이 아닙니다 — 점수 경로가 새로 살아납니다

수정 전에는 토너먼트 방으로 들어가는 데 매번 실패했고, 그래서 판은 항상 혼자 방에서 진행됐습니다. 점수 등록·순위 갱신·공유는 모두 "토너먼트 방일 때만" 동작하는 코드라 실행된 적이 없습니다. 이제 참가가 실제로 되니까 그 코드들이 처음으로 돌기 시작합니다 — 점수가 오르고, 클리어 후 공유·초대가 뜨고, 미션이 오릅니다. 그래서 C 섹션을 반드시 봐야 합니다.

목록이 짧아지는 건 정상입니다

페이스북은 내가 만든 것 · 내가 이미 참가한 것 · 친구가 참가한 것만 참가를 허용합니다. 모르는 사람의 토너먼트는 원칙적으로 참가할 수 없어서, 눌러도 실패할 항목을 미리 걸러냈습니다. 친구가 토너먼트를 하고 있지 않으면 목록이 만들기 칸만 남을 수 있고, 그것도 정상입니다.

준비

항목 내용
빌드 prod(라이브) 빌드 필수. dev 빌드는 서버가 실제 페이스북 토너먼트가 아닌 데이터를 주기 때문에 무조건 실패합니다 — dev에서 실패해도 버그가 아닙니다
계정 튜토리얼 완료 계정 2개(서로 친구). 한쪽이 토너먼트를 만들어 두어야 다른 쪽 목록에 친구 토너먼트가 생깁니다
사전 세팅 계정 B로 판을 깨고 토너먼트 만들기 → 계정 A로 로비 → 토너먼트 팝업에 그 토너먼트가 보여야 A 섹션 진행 가능
확인 수단 화면 동작 + 토너먼트 순위표. 로그로 볼 때는 3000/3010/3020(전환), 3300/3310/3320(점수 등록), 3200 계열(공유)
먼저 못 박습니다 — 정상이지만 이상해 보이는 것

① 토너먼트 목록이 예전보다 적게 보입니다(참가 불가 항목 제외). ② 내가 만든 토너먼트는 만든 세션에서만 목록에 보입니다 — 앱을 껐다 켜면 사라지는 게 기존 동작입니다. ③ 참가를 눌렀을 때 다이얼로그가 안 뜨는 것이 이번 수정의 핵심입니다. 이슈로 올리지 마세요.

A. 목록 · 진입 참가를 누른 뒤 프리게임 팝업까지

순서 이렇게 하면 이래야 정상
A-1 로비에서 토너먼트 팝업 열기 목록이 뜬다. 친구가 참가 중인 토너먼트가 앞쪽에 보인다
A-2 목록의 항목 하나에서 참가 누름 다이얼로그 없이 프리게임 팝업이 바로 뜬다
A-3 A-2의 프리게임 팝업을 그냥 닫음 로비로 돌아온다. 참가도 안 되고 다이얼로그도 안 뜬다
A-4 A-3 직후 로비에서 일반 플레이로 판 시작 아까 고른 토너먼트가 따라붙지 않는다 — 평소 판 시작과 동일
A-5 목록 2페이지까지 넘겨보기 페이지 이동 정상. 빈 칸·깨진 칸 없음
A-6 친구가 토너먼트를 하나도 안 만든 상태로 목록 열기 만들기 칸만 남을 수 있다 (정상)
A-3·A-4가 확인하는 것

참가 정보는 프리게임 팝업이 들고 있다가 Play를 누를 때 한 번만 씁니다. 팝업을 닫으면 그 정보는 버려져야 하고, 다음 판에 남아 있으면 안 됩니다. 남아 있으면 엉뚱한 판에서 토너먼트 다이얼로그가 뜹니다.

B. 참가 · 거절 이번 수정의 핵심

순서 이렇게 하면 이래야 정상
B-1 참가 → 프리게임 팝업 → Play 전환 다이얼로그가 한 번 뜬다
B-2 B-1의 다이얼로그에서 수락 판이 시작된다. 내가 고른 그 토너먼트에 참가된 상태여야 한다
B-3 B-2로 시작한 판을 클리어 → 그 토너먼트 순위표 확인 내 점수가 그 토너먼트에 올라가 있다
B-4 다시 참가 → Play → 다이얼로그에서 거절(X) 다이얼로그가 다시 뜨지 않는다. 전면광고 후 혼자 방에서 판이 시작된다
B-5 B-4를 연속 3번 반복 매번 다이얼로그는 1번만. 2번 이상 뜨면 버그
B-6 B-4로 시작한 판 클리어 토너먼트 순위에 안 올라간다(거절했으므로 정상). 혼자 판 클리어와 동일하게 처리
B-7 이미 참가 중인 토너먼트를 다시 참가 → Play 다이얼로그 없이 바로 판 시작(같은 방이므로 정상)
B-2·B-3이 최우선

고른 것과 다른 토너먼트에 들어가면 즉시 보고해주세요. 검증 도중 다른 토너먼트로 대체 참가하는 진단 코드를 넣었다 뺐는데, 그 흔적이 남아 있으면 여기서 드러납니다. 순위표에서 토너먼트 제목·참가자 목록이 내가 고른 것과 일치하는지 봐야 합니다.

B-5는 반복이 중요합니다

수정 도중 거절할 때마다 다이얼로그가 계속 다시 뜨는 문제가 있었습니다(최대 10번). 원인은 제거했지만, 재발하면 유저가 빠져나갈 수 없는 상태가 되므로 반드시 3회 이상 반복해주세요.

C. 점수 · 공유 · 미션 처음 동작하는 구간 — 가장 위험

순서 이렇게 하면 이래야 정상
C-1 참가한 토너먼트 판 클리어 순위표에 내 점수 반영. 이전 점수보다 낮으면 낮은 점수로 내려가지 않아야 한다
C-2 C-1 직후 화면 공유 또는 초대 다이얼로그가 뜬다(둘 중 하나·번갈아). 안 뜨는 조건도 있으니 아래 주석 참고
C-3 C-2에서 공유 성공 → 미션 확인 토너먼트 미션 진행도가 1 오른다
C-4 참가한 판을 중간에 나가기(포기) 점수가 안 올라가거나 그 판 획득분만 반영. 순위가 내려가지 않는다
C-5 참가한 판 클리어 후 연승 스타 획득 연출 순위표 점수가 그 값만큼 추가로 반영될 수 있다(정상). 중복 가산은 아니어야 한다
C-6 C-1 후 로비 복귀 → 다음 판을 일반 플레이로 시작 그 판 점수가 이전 토너먼트에 올라가지 않는다
C-7 참가한 판에서 재도전 사용 같은 토너먼트가 유지되고, 점수는 재도전 결과 기준으로 1회만 반영
C-8 C-1의 순위표에서 내 순위 숫자 확인 점수 대비 순위가 맞다. 1위가 아닌데 1위로 표시되면 보고
C-6이 회귀 위험 1순위

토너먼트 방은 판이 끝나도 바로 풀리지 않습니다. 다음 판을 시작할 때 정리되는 구조라, 그 사이에 점수가 엉뚱한 토너먼트로 흘러가면 남의 순위표에 내 점수가 꽂히는 사고가 됩니다. C-1 → 로비 → 일반 플레이 → 클리어를 한 번은 꼭 이어서 확인해주세요.

C-2가 안 뜨는 게 정상인 경우

누적 승수가 적고 튜토리얼을 안 끝낸 계정, 직전에 이미 공유·초대가 떠서 쿨다운인 경우, 토너먼트가 이미 종료된 경우에는 안 뜹니다. 이건 기존 규칙(SPEC-038)이고 이번 수정과 무관합니다.

C-8은 표시 값만의 문제

순위 숫자는 참가 시점에 저장한 값 또는 서버 캐시에서 추정합니다. 참가 경로에서는 참가 시점 순위를 저장하므로 정확해야 하지만, 어긋나도 점수 자체가 틀린 것은 아닙니다. 로그 값 정확도 이슈로 분리해서 보고해주세요.

D. 회귀 건드리지 않은 경로가 그대로인지

순서 이렇게 하면 이래야 정상
D-1솔로 판 클리어 → 토너먼트 만들기기존과 동일하게 만들어지고 목록에 보인다
D-2로비 토너먼트 탭에서 직접 만들기기존과 동일. 만든 직후 목록 맨 앞에 보인다
D-3토너먼트 초대 링크로 게임 진입바로 그 토너먼트 방에서 시작. 전환 다이얼로그 없음
D-4친구와 1:1 대결 진행상대·방 유지, 결과 전달 정상
D-5로비 일반 플레이로 판 시작 반복친구·토너먼트 추천 다이얼로그가 기존 빈도로 뜬다
D-6튜토리얼 계정(레벨 1~2)으로 진행전환 다이얼로그가 뜨지 않고 판으로 직행
D-7토너먼트 팝업 열기 → 즉시 닫기를 빠르게 반복멈춤·중복 팝업 없음. 로딩이 계속 걸려 있지 않다
D-7은 새로 생긴 대기 때문입니다

목록을 만들 때 참가 가능한 토너먼트가 무엇인지 페이스북에 한 번 물어봅니다. 그만큼 팝업이 느려질 수 있는데, 로딩이 끝까지 안 사라지거나 닫았는데 다시 뜨면 버그입니다.

알려진 이슈 · 이번 범위 밖 보고는 환영하지만 이번 수정 대상이 아님

현상 상태
판 시작 시 추천으로 뜬 토너먼트 전환을 수락했는데 참가되지 않음 미수정. 추천 경로는 아직 참가 불가한 토너먼트를 대상으로 삼는다 — 별도 작업 예정
내가 만든 토너먼트가 다음 세션 목록에 안 보임 기존 정책(만든 세션에서만 노출). 변경 여부 확인 중
목록에 뜨는 토너먼트 개수가 계정마다 다름 정상. 친구의 참가 상황에 따라 달라진다
dev 빌드에서 참가가 항상 실패 정상. dev 서버 데이터가 실제 페이스북 토너먼트가 아니다 — prod로 테스트
