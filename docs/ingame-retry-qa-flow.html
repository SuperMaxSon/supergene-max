인게임 재도전 — QA 가이드

판을 진행하다가 설정 버튼 → 재도전을 누르면, 로비를 거치지 않고 같은 스테이지로 판을 다시 시작합니다. 재도전 버튼만 눌렀을 때는 아직 아무것도 확정되지 않고, 프리게임 팝업에서 Play를 누르는 순간 이전 판이 포기 처리됩니다.

솔리테어 · 커밋 9d4ee385 2026-08-12 실기 미검증

동작 흐름도 Play를 누르기 전까지는 언제든 원래 판으로 돌아올 수 있습니다

이 기능에서 볼 것은 결국 두 지점입니다

취소 지점(팝업을 닫으면 판이 온전히 돌아오는가)과 확정 지점(Play 이후 이전 판이 정확히 한 번만 정산되는가). 나머지는 기존 프리게임 팝업과 같은 동작이라 회귀 확인만 하면 됩니다.

전면광고는 "확정 전"에 나옵니다

재도전을 누르면 프리게임 팝업보다 먼저 전면광고 판정이 돕니다. 그래서 광고를 보고 나서 팝업을 그냥 닫는 것도 정상 동작입니다 — 그때도 판은 그대로 유지되고 아무것도 차감되지 않습니다. 광고는 조건에 맞을 때만 나오므로 안 나오는 게 기본이라고 보시면 됩니다. 자세한 조건은 E 항목에 있습니다.

"같은 스테이지"지 "같은 보드"가 아닙니다

스테이지 ID와 난이도는 이전 판과 같지만, 카드 배치는 매번 새로 섞입니다. 재도전했는데 보드 모양이 달라진 것은 정상입니다. 이슈로 올리지 않아도 됩니다.

준비

항목 내용
빌드 솔리테어 dev 빌드. 재도전 버튼은 인게임 설정팝업에만 있습니다
버튼 위치 판 진행 중 우상단 설정(톱니) → 팝업 안 재도전
YouTube 빌드 현재 재도전 버튼이 없습니다 — 검증 대상 아님 (아래 알려진 이슈 K-3)
골드 준비 재도전은 입장료를 다시 받습니다. 골드 부족 케이스(B-3)도 봐야 하므로 부족 계정도 한 개 준비
전면광고 재도전 터치 직후 프리게임 팝업보다 먼저 판정합니다. 조건은 E 항목 참고 — 안 나오는 게 기본
확인용 값 재도전 전후의 골드 · 부스터 개수 · 스테이지 번호 · 난이도 표시를 매번 적어 두기
기록을 남겨야 판정되는 항목이 많습니다

"골드가 두 번 빠진 것 같다", "미션이 더 올라간 것 같다" 같은 제보는 이전 값이 없으면 확인이 불가능합니다. 재도전 직전 값을 스크린샷으로 남겨 주세요.

A. 기본 동작 일반 판(프리게임 팝업이 뜨는 그룹) 기준

순서 이렇게 하면 이래야 정상
A-1 판 진행 중 설정 → 재도전 터치 설정팝업이 닫히고 프리게임 팝업이 뜬다. 뒤에는 진행 중이던 보드가 보인다
A-2 A-1 상태에서 스테이지 번호 · 난이도 확인 진행 중이던 판과 같은 스테이지 · 같은 난이도로 표시된다
A-3 Play 터치 로비를 거치지 않고 같은 스테이지로 새 판이 시작된다. 입장료가 다시 차감된다
A-4 A-3 직후 이전 판에서 모았던 골드 · 별 확인 지급되지 않는다 (포기와 같은 처리). 보드·타이머·부스터 카운트는 전부 초기화
A-5 프리게임 팝업에서 부스터를 골라서 Play 고른 부스터가 정상 소모되고 새 판에 적용된다
A-6 재도전을 연속 3회 반복 매번 정상 시작. 팝업 겹침 · 버튼 먹통 · 검은 화면이 없어야 한다
A-7 재도전한 판을 끝까지 클리어 결과창 · 보상 · 미션 · 다음 난이도가 평소와 동일하게 나온다
A-4가 이 기능의 정의입니다

재도전은 "포기 + 같은 스테이지 재시작"입니다. 이전 판에서 모은 보상이 넘어오면 골드 무한 증식이 되므로 가장 먼저 확인해야 합니다.

B. 취소 — 원래 판으로 돌아오는지 각각 따로 실행. 매번 직전 골드 값을 적어 두고 비교

순서 이렇게 하면 이래야 정상
B-1 재도전 → 프리게임 팝업에서 X 터치 진행 중이던 판이 그대로 돌아온다. 카드 배치 · 남은 카드 수 · 부스터가 전부 유지
B-2 B-1 직후 골드 · 부스터 개수 확인 1도 줄지 않았다
B-3 골드가 부족한 상태에서 재도전 → Play 광고 골드 / 상점 팝업이 뜬다. 닫으면 원래 판으로 복귀하고 아무것도 차감되지 않는다
B-4 B-1로 복귀한 판을 그대로 클리어 결과창 · 보상이 정상. 재도전을 눌렀던 흔적이 남지 않는다
B-5 재도전 → 취소 → 다시 재도전 두 번째도 정상적으로 팝업이 뜬다 (버튼이 먹통이 되지 않는다)
B-6 재도전 → 취소 → 설정 → 나가기(기존 포기) 기존 포기 플로우가 그대로 동작한다
B-5는 눈에 안 띄지만 치명적입니다

취소 처리가 한 군데라도 빠지면 재도전 버튼이 그 판 내내 먹통이 됩니다. 화면상으로는 아무 일도 없어 보여서 놓치기 쉽습니다. 취소한 뒤에는 반드시 한 번 더 눌러 보세요.

C. 실패 · 복구 Play 이후 잘못됐을 때 어떻게 되는지

순서 이렇게 하면 이래야 정상
C-1 재도전 Play 직전에 비행기 모드 → Play 에러 팝업이 뜨고, 확인하면 로비로 나간다 (이전 판은 이미 정산됐으므로 정상)
C-2 C-1 이후 로비에서 골드 · 미션 · 스테이지 진행도 확인 이전 판이 포기 1회로만 반영돼 있다. 골드가 이중으로 빠지지 않았다
C-3 C-1 이후 로비에서 다시 판 진입 정상 진입한다 (진입 자체가 막히지 않는다)
C-4 재도전 Play 직후 앱을 강제 종료 → 재실행 골드 · 미션이 이중 반영되지 않는다. 판이 깨진 상태로 복구되지 않는다
C-1에서 "로비로 나가는 것"은 버그가 아닙니다

Play를 누른 시점에 이전 판은 이미 서버에서 종료됩니다. 새 판까지 실패하면 돌아갈 판이 없어서 로비로 내보내는 것이 설계된 동작입니다. 대신 C-2처럼 정산이 한 번만 됐는지가 확인 대상입니다.

C-1에서 에러 팝업이 두 개 뜰 수 있습니다 — 이미 알려진 이슈

서버가 에러코드를 돌려주는 경우에 한해 에러 팝업이 2개 겹쳐서 뜹니다 (아래 K-1). 확인을 두 번 눌러야 로비로 나갑니다. 중복 제보하지 않아도 됩니다 — 대신 그때 골드가 몇 번 빠졌는지는 꼭 적어 주세요.

D. 기존 기능이 그대로인지 이번 작업이 프리게임 팝업과 인게임 정산을 같이 건드렸습니다

순서 이렇게 하면 이래야 정상
D-1 로비에서 평소대로 판 진입 (재도전 안 씀) 프리게임 팝업 · 부스터 · 배수 · 친구 랭킹이 전부 기존과 동일
D-2 인게임 설정 → 나가기 (기존 포기) 기존 포기 팝업 · 로비 복귀가 그대로
D-3 인게임 엔드레벨 버튼 기존 보상 팝업이 그대로
D-4 토너먼트 판에서 재도전 → Play 토너먼트에서 튕겨 나가지 않는다. 이전 판까지의 점수는 등록돼 있다
D-5 튜토리얼 레벨(1~2렙)에서 재도전 정상 재시작. 튜토리얼 안내가 다시 나오지 않는다 (정상)
D-6 재도전 후 로비로 나가서 냥이 추격전 발동 확인 발동 조건을 채웠다면 로비에서 정상적으로 뜬다
D-7 재도전 여러 번 후 데일리 미션 카운트 확인 "판 플레이" 미션이 재도전 횟수만큼 올라간다 (현재 사양 — 아래 K-4)
D-4와 D-6이 이번 작업에서 가장 깨지기 쉬운 곳

재도전은 로비를 거치지 않는 유일한 재시작 경로입니다. 토너먼트 연결 상태와 냥이 추격전 발동 감지가 원래 "로비를 지나갈 때" 처리되던 것이라, 이 두 개만 따로 손을 봤습니다. 나머지 항목보다 우선해서 봐 주세요.

E. 전면광고 재도전 터치 직후, 프리게임 팝업이 뜨기 전에 판정합니다

광고가 안 나오는 게 기본입니다

아래 조건이 전부 맞아야 나옵니다. 하나라도 걸리면 광고 없이 바로 프리게임 팝업으로 넘어갑니다. "재도전했는데 광고가 안 떴다"는 이슈가 아닙니다. 반대로 조건에 안 맞는데 떴다면 그건 이슈입니다.

조건 내용
레벨 6레벨 이상. 5레벨 이하는 무조건 안 나옵니다
튜토리얼 튜토리얼 진행 중이면 안 나옵니다
누적 접속 누적 로그인 횟수가 기준치 이상이어야 합니다
하루 상한 당일 전면광고 노출 상한에 도달했으면 안 나옵니다
직전 광고와 간격 최소 30초. 직전 광고 후 30초가 안 지났으면 안 나옵니다
클리어 간격 적용되지 않습니다 — 나가기 광고와 같은 취급이라 클리어 횟수를 세지 않습니다
순서 이렇게 하면 이래야 정상
E-1 조건을 만족한 계정으로 재도전 터치 설정팝업이 닫히고 광고 → 프리게임 팝업 순서로 진행된다
E-2 E-1에서 광고를 끝까지 보고 팝업에서 X 원래 판으로 복귀. 광고만 본 셈이고 아무것도 차감되지 않는다
E-3 E-1 직후 30초 안에 다시 재도전 광고 없이 바로 프리게임 팝업이 뜬다 (최소 간격)
E-4 광고 도중 닫기 / 건너뛰기 정상적으로 프리게임 팝업으로 넘어간다. 멈추지 않는다
E-5 5레벨 이하 계정으로 재도전 광고가 절대 안 나온다
E-6 광고가 나온 뒤 Quick Next Loop 그룹에서 재도전 광고 후 팝업 없이 곧바로 새 판이 시작된다
E-4가 제일 잘 깨집니다

광고를 중간에 닫거나 로딩에 실패했을 때 화면이 멈추면 유저는 판도 잃고 나가지도 못합니다. 광고를 정상 시청한 경우보다 중단·실패했을 때를 더 많이 눌러 봐 주세요.

E-2는 기획 판단이 필요한 항목입니다

광고가 재도전을 확정하기 전에 나오는 구조라, 광고를 보고 취소하면 유저 입장에서 "광고만 본" 상태가 됩니다. 동작 자체는 설계대로이므로 버그가 아닙니다. 다만 이런 흐름이 얼마나 자주 나오는지 알아야 해서, E-2가 거슬리게 느껴졌다면 그 느낌을 그대로 적어 주세요.

이미 알고 있는 것 코드 리뷰에서 확인된 항목 — 중복 제보 불필요

# 증상 상태 QA가 해줄 것
K-1 새 판 시작이 서버 에러로 실패하면 에러 팝업이 2개 겹친다 (통신이 아예 끊긴 경우는 1개로 정상) 확정 · 미수정 겹치는 것 말고 골드가 몇 번 빠졌는지만 기록
K-2 광고가 안 나온 재도전에서, 팝업이 뜨기 전 짧은 순간 보드와 엔드레벨 버튼이 눌린다 확정 · 미수정 일부러 연타해서 결과창과 프리게임 팝업이 겹치는지 확인
K-7 재도전 광고만 따로 끄는 스위치가 없다 (나가기 광고는 있음) 확정 · 기획 확인 중 해당 없음
K-3 YouTube 빌드에는 재도전 버튼이 없다 확정 · 기획 확인 중 검증 대상 아님
K-4 재도전할 때마다 "판 플레이" 미션이 1씩 올라간다 현재 사양 · 정책 확인 중 숫자만 기록 (버그로 올리지 않음)
K-5 Play 직후 팝업 닫힘 연출과 새 보드 등장이 살짝 겹쳐 보인다 확정 · 연출 이슈 심하게 튀는 기기가 있으면 기종명과 함께 제보
K-6 재도전 버튼 클릭 로그가 없다 로그표 확정 대기 해당 없음
이 표를 읽는 법

확정은 코드에서 원인까지 확인된 것이고, 확인 중은 기획·정책 답이 나와야 버그인지 사양인지 정해지는 것입니다. 어느 쪽이든 새 이슈로 올릴 필요는 없지만, 표의 "QA가 해줄 것" 칸은 채워 주셔야 수정 방향이 정해집니다.

증상 어긋난 항목

재도전을 취소했는데 골드나 부스터가 줄었다 B-2 · B-3 (최우선)
재도전 한 번에 골드가 두 번 빠졌다 C-2 (최우선 — 이중 정산)
취소하고 나서 재도전 버튼이 더 이상 안 눌린다 B-5
취소했는데 보드가 초기화돼 있거나 다른 판으로 바뀌었다 B-1
재도전 후 스테이지 번호나 난이도가 달라졌다 A-2
토너먼트 판에서 재도전했더니 토너먼트에서 빠져나왔다 D-4
재도전 후 로비에서 냥이 추격전이 발동했어야 하는데 안 떴다 D-6
재도전 반복 후 검은 화면 · 팝업 먹통 · 버튼 무반응 A-6
