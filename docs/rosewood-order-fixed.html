고정 오더

추첨이 아닙니다. order_fixed 에 요구품이 박혀 있고, 순번(fixed_seq)대로 한 장씩 나갑니다. 레벨은 각 행의 unlock_level 로 자동 진행하며 랜덤 오더는 섞지 않습니다 — 실제 플레이는 Lv3 부터 둘이 섞이지만, 그걸 재현하려면 오더 하나당 경험치가 있어야 레벨업 시점이 잡힙니다. 시트에 그 열이 없어 가정을 지어내야 하므로 그리지 않습니다.

순서대로 — 위가 코인과 난이도, 아래가 이벤트 재화입니다. 난이도만 그림 대신 글자인 건 게임 화면에 없는 분석값이기 때문입니다 — 실제 카드에는 안 나옵니다. 난이도 숫자 색은 자릿수 구간(~9 · ~99 · ~999 · 1000~)입니다 — 시트에는 난이도 구간이 없어서 이 페이지가 정한 값입니다. 손님 색은 order_avatar 행 순서로 나눴습니다. 손님 얼굴은 이 화면에서 유일한 난수라 고정 시드로 한 번만 뽑습니다.
