토너먼트 만들기 다이얼로그를 연속 3번 취소하면 그 뒤로는 안 뜹니다. 원래 동작이고 이번 수정과 무관합니다. 이슈로 올리지 마세요. 다시 뜨게 하려면 앱을 껐다 켜거나, 한 번 만들기에 성공하면 됩니다.

A. 기본 동작 끊지 말고 순서대로 · 네트워크 정상 상태

순서 이렇게 하면 이래야 정상
A-1 솔로로 판 클리어 토너먼트 만들기 다이얼로그가 뜬다
A-2 A-1에서 만들기 누름 만들어지고, 로비 토너먼트 목록에 내 토너먼트가 보인다
A-3 A-2에서 만든 토너먼트를 열어봄 내 점수가 들어가 있고 1위
A-4 다음 판 클리어 → 다이얼로그에서 취소 닫히고, 그 다음 판에서 또 뜬다
A-5 취소를 연속 3번 그 뒤로는 안 뜬다 (정상)
A-6 로비 토너먼트 탭에서 직접 만들기 만들어진다. A-5로 막힌 상태여도 여기는 영향 없음
A-6

로비에서 직접 만드는 건 취소 횟수와 무관합니다. A-5로 막혀 있어도 여기서는 항상 만들 수 있어야 합니다.

B. 핵심 검증 이번 수정이 고친 부분

순서 이렇게 하면 이래야 정상
B-1 판 클리어 → 만들기 다이얼로그가 뜬 상태에서 네트워크 차단 → 만들기 누름 → 네트워크 복구 오류가 보이더라도, 로비 토너먼트 목록에 그 토너먼트가 있어야 한다
B-2 B-1에서 만들어진 토너먼트를 열어봄 내 점수가 들어가 있어야 한다
B-3 취소 2번 → 3번째 다이얼로그에서 B-1처럼 네트워크 끊고 만들기 → 이후 판에서 취소 2번 더 계속 다이얼로그가 뜬다. 수정 전에는 여기서 한 번만 취소해도 안 떴다
B-4 친구·토너먼트 초대 링크로 게임 진입 → 로비로 나감 → 솔로로 판 클리어 만들기 다이얼로그가 뜬다 (공유·초대가 아니라)
B-5 B-4 중 로비 진입·나가기, 리더보드·토너먼트 팝업 열고 닫기를 빠르게 반복 화면이 2초 넘게 멈추지 않는다. 버튼이 계속 눌린다
B-1·B-2가 최우선

여기서 토너먼트가 없거나 점수가 안 들어가 있으면 수정이 안 먹은 겁니다. 오류 메시지가 보이는 것 자체는 버그가 아닙니다 — 네트워크를 끊었으니 당연합니다. 중요한 건 그 뒤에 토너먼트가 실제로 남아 있는지입니다.

B-3은 순서를 정확히 지켜야 합니다

취소 2번 → 네트워크 끊고 만들기 → 취소 2번. 중간에 앱을 껐다 켜면 횟수가 초기화되어 판정이 무의미해집니다. 한 번에 이어서 진행하세요.

B-4가 확인하는 것

초대 링크로 들어오면 친구·토너먼트 방에 묶인 상태입니다. 로비로 나갈 때 혼자 방으로 풀려야 하는데, 그게 늦어지면 다음 판에서 엉뚱한 다이얼로그가 뜹니다. 만들기가 떠야 정상입니다.

C. 회귀 건드리지 않은 부분이 그대로인지

순서 이렇게 하면 이래야 정상
C-1토너먼트 판 클리어공유 또는 초대 다이얼로그가 기존대로 뜬다
C-2친구와 1:1 대결 진행상대·방이 유지되고 결과 전달 정상
C-3인게임 나가기 → 로비 → 다시 판 진입멈춤 없이 진입, 판 수·난이도 정상
C-4리더보드 팝업 열고 닫기즉시 닫히고 로비 조작 가능
C-5토너먼트에 참가 → 판 진행 → 클리어순위에 점수 반영
C-6네트워크 정상 상태에서 만들기 성공A-2·A-3과 동일. 오류 메시지 없음
C-3·C-4가 중요합니다

혼자 방으로 돌아가는 처리가 여기저기서 일어납니다. 대기 시간을 줄인 수정이라 멈춤이 사라지는 방향이어야 하고, 반대로 화면이 굳거나 버튼이 안 먹으면 문제입니다.
