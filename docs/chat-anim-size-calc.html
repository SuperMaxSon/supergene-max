노드 트랜스폼 애니메이션은 노드 트리로 파츠를 분리하고 cc.Animation 으로 position/scale/angle/opacity 키프레임만 찍는 방식입니다. 루나 클립 7종 전부 spriteFrame 키가 0개인 걸로 확인했습니다. Spine 처럼 보이지만 외부 툴도 런타임도 쓰지 않습니다. “본 애니메이션”은 틀린 이름입니다 — 본이 없고 노드 계층 트랜스폼뿐입니다.

확인 범위 puzzle-omg 5세트가 사내에 존재하는 캐릭터 Spine 전부입니다 — 솔리테어·코지·마종·블록블라스트· 스페이스블라스트는 .atlas 0개이고, 각 리포의 SpinePlayerOnEnable.ts 는 붙일 에셋이 없는 템플릿 보일러플레이트입니다. coin-match gold_pig(221 KB)은 감정 표현이 아닌 연출용이라 회귀에서 제외했습니다. 루나 파츠는 1.603 B/px 로 사내에서 압축이 가장 비효율적이어서 노드 계수는 보수적입니다. 모든 용량은 10진 소스 파일 기준이며, GPU 텍스처 메모리는 별도입니다 — 채팅 얼굴은 감정당 5.95 MB, 16감정 전체 95.3 MB.
