위에서 낙하 node.y + delay 없음 시작 y 를 화면 밖까지 올려야 잘려 들어오는 게 안 보인다
낙하 + 착지 스쿼시 y → scaleY 연결 없음 앵커가 이미지 하단 끝이라 밑변이 기준선이 된다. 밑끝이 접지점이 아닌 지붕 · 굴뚝에는 걸지 말 것
아래에서 팝 scale 0.25 → 1 없음 2.4 의 scale 은 단일 값(균등). 축을 나누려면 scaleX / scaleY
페이드 인 / 아웃 node.opacity 0 ↔ 255 없음 자식까지 같이 흐려지려면 부모의 cascadeOpacity 를 켤 것
Fill 가로 / 세로 Sprite.Type.FILLED + fillRange 정점 갱신 FILLED 는 SLICED(9-slice) 와 배타적이다. 아이소 파츠에서는 화면 축으로 잘린다
확인 범위 이징 곡선은 cc.tween 이 쓰는 공식을 그대로 옮겨 계산해서 타이밍은 엔진과 같게 보입니다. 실제 렌더 결과(아틀라스 배칭 · 알파 · 드로우콜)는 씬에서 한 번 확인해야 합니다.
