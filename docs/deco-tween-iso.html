아이소메트릭 데코 영역 — 등장 연출 · 레이어

데코레이션이 배치될 때 쓸 등장 연출을 실제 타이밍 그대로 돌려봅니다. 영역은 비어 있는 상태에서 시작합니다 — 수리형의 낡은 상태만 예외로 이미 놓여 있습니다. 게임과 같이 미션을 하나씩 눌러야 오브젝트가 등장합니다 — 아트 인계 문서의 네 유형을 그대로 깔았습니다. 배치형은 한 번에 놓이고, 건설형(집)은 터 → 벽 → 지붕으로 자라며, 수리형(분수)은 낡은 것이 처음부터 놓여 있다가 누르면 새 것으로 교체되고, 선택형(가로등)은 카드 3장 중 하나를 고릅니다. 보간 시간 1초는 오브젝트 root 하나가 등장하는 시간입니다. 그 1초 안에서 root 안의 스프라이트가 조립 순서대로 조금씩 늦게 들어오고, 딜레이는 root 와 root 사이에 둡니다. 등장 연출 9종에는 키값이 붙어 있습니다 — DROP_IN · POP_UP · FILL_FROM_LEFT 처럼, 기획서와 코드가 같은 이름으로 부르는 값입니다. 키값을 고르면 그 연출의 값 · 이징이 아래 표로 뜨고, 숫자를 치거나 슬라이더를 끌면 무대와 코드가 그 값으로 바뀝니다. 맞춘 값은 이 브라우저에 남아 새로고침해도 그대로이고, [설정 주고받기] 로 텍스트째 주고받습니다. Cocos Creator 2.4 에서 되는 연출만 실었습니다 — 엔진이 기본 지원하지 않는 것은 뺐습니다.

코드 위 파라미터가 그대로 들어간 Cocos Creator 2.4 구현

지원 범위 Cocos Creator 2.4 · 여기 있는 9종은 전부 엔진 기본 기능

키값 · 이름 손대는 것 추가 비용 주의
DROP_IN
떨어져 놓임		 node.y + delay 없음 시작 y 를 화면 밖까지 올려야 잘려 들어오는 게 안 보인다
DROP_SQUASH
떨어져 눌림		 y → scaleY 연결 없음 앵커가 이미지 하단 끝이라 밑변이 기준선이 된다. 밑끝이 접지점이 아닌 지붕 · 굴뚝에는 걸지 말 것
POP_UP
솟아 놓임		 scale 0.25 → 1 없음 2.4 의 scale 은 단일 값(균등). 축을 나누려면 scaleX / scaleY
FADE_IN
스며 나타남		 node.opacity 0 → 255 없음 자식까지 같이 흐려지려면 부모의 cascadeOpacity 를 켤 것
FADE_OUT
스며 사라짐		 node.opacity 255 → 0 없음 퇴장이라 트윈이 끝나면 active = false 까지 해 준다. 진행 중인 트윈부터 stopAllByTarget
FILL_FROM_LEFT
왼쪽부터 채워짐		 FillType.HORIZONTAL · fillStart 0 정점 갱신 FILLED 는 SLICED(9-slice) 와 배타적이다. 잘리는 선은 화면 세로선이라 아이소 사면을 따라가지 않는다
FILL_FROM_RIGHT
오른쪽부터 채워짐		 fillStart 1 · fillRange 음수 정점 갱신
FILL_FROM_BOTTOM
아래부터 채워짐		 FillType.VERTICAL · fillStart 0 정점 갱신 같은 제약. 잘리는 선은 화면 기준 수평선이다
FILL_FROM_TOP
위부터 채워짐		 fillStart 1 · fillRange 음수 정점 갱신
