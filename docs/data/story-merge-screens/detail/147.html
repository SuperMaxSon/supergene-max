의도적 이탈 (결함 아님)
  1. 설명 키 T_UNLOCK_FEATURE_INVENTORY_DESC/SHOP_DESC 는 클라 신규 키(구멍) — 시트에 행이 없다
  2. 기능명은 전용 키가 없어 화면 제목 키(T_INVENTORY_TITLE_LABEL·T_SHOP_TITLE)를 빌려 쓴다
  3. 뜨는 순간 「봤음」 기록(×·Later·Check it out 공통) — 같은 안내 반복 방지
  4. Check it out 이면 이동하고 남은 안내는 다음 마을 진입으로 미룬다 — 기획 규칙 없음
  5. 대상은 저장하지 않고 표시 레벨·show_tutorial·본 기록에서 파생 — 안내 전 종료돼도 다음 진입에 다시 뜬다
  6. 목적지 없는 콘텐츠는 Check it out 을 숨긴다(현 show_tutorial=true 는 인벤토리·상점뿐이라 비노출)
  7. 「기능 해금」 은 「세부 내용 미정 · 확정 전 참고자료」(tbd) 상태
