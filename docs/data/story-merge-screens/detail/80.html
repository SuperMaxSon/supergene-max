기획서 대비 어긋난 것
  1. 소진 판정이 심부름만 본다 오구현 · 중 — 정본은 공개 심부름 전부 완료·남은 꾸미기 자리 0·대기 스토리 없음 셋이 모두 참일 때다. 코드는 다음 날 심부름 행 유무만 본다 PopupChore.ts:361-367 · tab-outgame §2.2.5 [조건]
  2. 완료 직후 자동 1회 노출 없음 누락 · 중 — 마지막 심부름 완료 연출 뒤 한 번 자동으로 띄우고 본 기록을 남겨야 한다. 사이클 끝(꾸미기→레벨업→해금→새날)에 「준비된 내용 소진 안내」 을 여는 곳이 없고 본 기록도 없다 PopupChore.ts:690-699 · LevelUpFlow.ts:62-64 · tab-outgame §2.2.5 흐름 4~6
  3. 갱신 시각을 클라가 셈 오구현 · 중 — next_content_update_at 이 없으면 날짜 줄을 빼야 한다. 코드는 단말 시계로 다음 UTC 자정을 만들어 찍는다 — 콘텐츠 갱신과 무관한 날짜 PopupChore.ts:1048-1060 · tab-outgame §2.2.5 [동작]·[예외]
  4. NPC 인물 그림 노드 없음 누락 · 하 — 패널 위에 겹치는 안내 화자 반신 컷(①) 자리가 cleared 묶음에 없다 PopupChore.prefab Contents/cleared · screen 「준비된 내용 소진 안내」 row 1
  5. 시각 표기 형식 충돌 · 하 — 「준비된 내용 소진 안내」 「MM/DD hh:mm (UTC)」와 2.2.5 [표기] 「UTC 연월일·시분초」가 다르다 screen 「준비된 내용 소진 안내」 row 5 · tab-outgame §2.2.5 [표기]
  6. 정본 문구 키 미사용 오구현 · 하 — T_CONTENT_EXHAUSTED_TITLE·BODY·NEXT_UPDATE 대신 T_CHORE_TITLE_CLEARED·T_CHORE_CLEARED 를 쓴다(문구는 같음) PopupChore.ts:400-401 · screen 「준비된 내용 소진 안내」 row 2·5
