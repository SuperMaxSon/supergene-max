개발 — 만들 것
  1. 부팅 판정 게이트(BaseIntro) — 순서는 점검→강제 업데이트. 서버 응답 CLIENT_UPDATE_REQUIRED(426)·MAINTENANCE를 받을 VersionGate 스텁을 두고, feature_toggle force_update·maintenance_mode를 읽는다
  2. Reload 동작 — FBInstant는 재초기화할 수 없다. PlayerStore 저장을 확정한 뒤 location.reload()로 재적재하고 실기 검증한다. 이후 「새날 전환 · New day」로 간다
  3. 세션 중 재적재 판 — TABLE_UPDATE_REQUIRED를 받으면 로컬 생산·오더 저장을 확정한 뒤 재부팅한다. 테이블 객체만 바꿔 끼우지 않는다
