기획서 대비 어긋난 것
  1. 표시용 ID 형식 미결 충돌 · 하 — 「플레이어 ID 복사」 row 1 「표시용 ID의 형식 · 출처는 서버 계약 확인 필요」 · 「플레이어 프로필」 row 7 「샘플 JGIEVAH는 실제 ID가 아님 · 표시용 ID 계약 확인 필요」 — 원천·길이·변환 규칙이 미결 계약으로 명시됐다. 코드는 FB playerID(가변 16자 안팎) PopupProfile.ts:174 getPlayerID · screen 「플레이어 ID 복사」 row 1 · screen 「플레이어 프로필」 row 7 · C25 id-field
의도적 이탈 (결함 아님)
  1. 복사 실패 시 토스트 없음 — 「플레이어 ID 복사」 row 2 「복사 성공 때만 표시」와 같다
  2. ID 값은 FB playerID — 서버 표시용 ID 확정 전까지(플랜 리스크 항목)
  3. 토스트 시간은 const.toast_show_sec, 못 읽으면 1.5초 폴백(GlobalToast.ts:11)
  4. 「연결 끊김」 연결 끊김이 떠 있는 동안은 전역 토스트가 멈춘다(SceneManager.suspendToast) — 그 팝업이 입력을 막아 복사 경로와 겹치지 않는다
