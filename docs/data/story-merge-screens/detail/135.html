기획서 대비 어긋난 것
  1. 선택 표시에 체크 배지 없음 누락 · 하 — 선택 표시는 테두리(selectRing)뿐이고 체크 배지 노드가 없다. 아트 목록 「선택 테두리·체크 배지」의 뒤쪽이 비었다 PopupAvatarPicker.prefab selectRing · screen 「아바타 선택」 row 3
  2. 저장 중 잠금 · 실패 안내 없음 누락 · 하 — 「저장 요청 중에는 조작을 잠그고 실패하면 재시도 안내(T_SYSTEM_SAVE_FAIL_RETRY)」. 코드는 로컬 장착 뒤 flush 를 부르고 바로 닫는다 — 잠금·실패 문구 경로가 없다(저장 API 없음, 연결 실패 안내는 ConnectionMonitor 가 따로 낸다) PopupAvatarPicker.ts:118-123 · screen 「아바타 선택」 row 5
  3. 변경 없이 Save 처리 문서 불일치 충돌 · 하 — 「플레이어 프로필」 row 12 「비활성 검토」 ↔ 「프로필 · 프레임 탭」 row 6 「Nothing changed 토스트」. 코드는 후자 — Save 는 항상 활성, 변경 없으면 T_PROFILE_FRAME_NOCHANGE_TOAST 후 닫힘, 바꿨으면 T_PROFILE_FRAME_SAVED_TOAST(아바타 저장 토스트 유무는 문서에 없다) PopupAvatarPicker.ts:105-123 · screen 「플레이어 프로필」 row 12 · 150 row 6
  4. 변경 횟수 제한 문서 공백 충돌 · 하 — A3 「한 번 고른 것을 몇 번까지 바꾸게 할지」가 열려 있다. 코드는 제한이 없다 PopupAvatarPicker.ts:118 · dev A3
의도적 이탈 (결함 아님)
  1. 잠긴 칸 탭 = 전역 토스트 「Opens at Day N」(AvatarRules.lockedHint · PopupAvatarPicker.ts:95-98) — 선택은 옮기지 않는다. 「목표 미션 안내」 툴팁은 런칭 범위 밖(사용자 결정 2026-09-30)
  2. 기본 아바타 = 로지(avatar_id portrait_rosie, AvatarRules.ts:9) — 저장하지 않고 equipped() 가 계산한다(AvatarRules.ts:57-68). 신규 유저 기본값이 문서에 없다
  3. FB 사진 대신 아바타 — 프로필 사진 자리와 HUD 배지가 장착 아바타를 그린다(PopupProfile.ts:121 · TopBarNode.ts:346). 장착 없음·그림 로드 실패 때만 FB 사진 폴백
  4. 해금 판정 = 심부름 Day 도달(chore.day ≥ unlock_val, AvatarRules.ts:43-51) — unlock_val 은 인물 첫 등장 Day(기획 회신 09-29). 그날 언제 열리는지는 문서에 없다
  5. 아바타 고르는 곳 = 「아바타 선택」 별도 판(프로필 사진 탭) — 「플레이어 프로필」 안 그리드·「프로필 · 프레임 탭」 탭 대신
  6. 저장 = PlayerState.avatarKey(PlayerState.ts:215, FB 저장 · 서버 API 없음) — Save 뒤 즉시 flush(PopupAvatarPicker.ts:119)
  7. 칸은 프리팹에 12개 — 시트 in_use 행(현 11행)만큼 켜고 넘으면 자른다(PopupAvatarPicker.ts:49-53)
  8. 초상은 임시 아이템 칩·자물쇠는 더미 아이콘(AvatarRules.ts:19 TEMP_ICON_CODES) — order/avatar/* 아트가 오면 로더만 바뀐다
