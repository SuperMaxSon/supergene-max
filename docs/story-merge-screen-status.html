한 줄 = 코드에서 창 하나로 만들어지는 단위입니다. 같은 창을 공유하는 화면 번호는 한 줄에 묶었고 (예: 149·169 팔기 확인), 라이브옵스와 오퍼는 화면이 전부 0이라 이벤트 하나를 한 줄로 세고 화면 수를 적었습니다. 섹션마다 남은 것만 펼쳐 두고 완료는 접어 뒀고, 남은 것은 기획 준비도가 높은 순(바로 만들 수 있는 것이 위)으로 정렬했습니다. 부분은 창은 있지만 기획서 화면을 다 채우지 못했거나 아직 커밋되지 않은 것입니다. 막대는 초록 → 노랑 → 빨강 → 회색 순으로 완료 · 부분 · 없음 · 제외 비율입니다.

기획 준비도 게이지

남은 항목마다 화면 · 규칙 · 데이터 · 문구 4축을 채움 1 · 구멍 0.5 · 없음 0 으로 매겨 평균을 냈습니다(해당 없는 축은 뺌). 칩 색이 축별 상태이고, 퍼센트 옆 완비 · 공백 · 미완이 판정입니다. 퍼센트는 「얼마나 써 있나」이고 판정은 「지금 막히나」라서 따로 읽습니다 — 출석은 축마다 뭔가 써 있어 50%지만 같은 화면 안에서 숫자가 어긋나 미완입니다. 100% 는 지금 바로 구현할 수 있다는 뜻입니다.
