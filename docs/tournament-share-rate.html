코드 결함 2개 — 성공이 실패로 집계된다

① NETWORK_FAILURE 복구 경로에 3110이 없다

FacebookPlatform.ts:640-658. random_key로 매칭해 실제 생성된 토너먼트를 찾아내고 서버 등록까지 호출하는데, 로그는 앞서 찍은 3120뿐입니다. 완전히 성공한 건이 100% 실패로 집계됩니다. 최대 8.1%p.

② 서버 등록 실패도 3120

FacebookPlatform.ts:674-682. FB에는 토너먼트가 생성됐는데 우리 서버 왕복이 실패하면 3120으로 남습니다. FB 기준 성공과 서버 기준 성공이 한 키에 섞여 구분이 불가능합니다.

그래서 「생성 성공률」은 실제 성공률이 아니다

현재 수치에는 로그 정의 결함이 섞여 있습니다. 이걸 먼저 고치지 않으면 이후 어떤 개선도 효과를 측정할 수 없습니다. 로그만 손대는 변경이라 동작 리스크는 없습니다.

쿼리

테이블명 = 코드의 app 값 · mahjong / cozy_tiles / puzzle_block_master(=퍼블마) / solitaire_city_journey

빌드별 생성 퍼널 (이 문서의 핵심 표) 
WITH ev AS (
  SELECT client_version, event, JSON_VALUE(data, '$.error_code') AS error_code
  FROM `game-log-359704.raw.solitaire_city_journey`
  WHERE log_date BETWEEN '2026-07-28' AND '2026-08-10'
    AND event IN ('2100_GAMEPLAY_START',
                  '3100_TOURNAMENT_CREATE',
                  '3110_TOURNAMENT_CREATE_SUCCESS',
                  '3120_TOURNAMENT_CREATE_FAIL')
)
SELECT
  client_version AS build,
  COUNTIF(event = '2100_GAMEPLAY_START')            AS plays,
  COUNTIF(event = '3100_TOURNAMENT_CREATE')         AS create_try,
  COUNTIF(event = '3110_TOURNAMENT_CREATE_SUCCESS') AS create_success,
  ROUND(100 * SAFE_DIVIDE(
    COUNTIF(event = '3120_TOURNAMENT_CREATE_FAIL' AND error_code = 'USER_INPUT'),
    COUNTIF(event = '3100_TOURNAMENT_CREATE')), 1)  AS reject_rate_pct,
  ROUND(100 * SAFE_DIVIDE(
    COUNTIF(event = '3100_TOURNAMENT_CREATE'),
    COUNTIF(event = '2100_GAMEPLAY_START')), 2)     AS try_per_play_pct,
  ROUND(100 * SAFE_DIVIDE(
    COUNTIF(event = '3110_TOURNAMENT_CREATE_SUCCESS'),
    COUNTIF(event = '2100_GAMEPLAY_START')), 3)     AS success_per_play_pct
FROM ev
GROUP BY build
HAVING create_try >= 300
ORDER BY build;
실패 코드 분포 (비거절 비중 확인) 
SELECT
  JSON_VALUE(data, '$.error_code') AS error_code,
  COUNT(*) AS cnt,
  ROUND(100 * COUNT(*) / SUM(COUNT(*)) OVER (), 1) AS pct
FROM `game-log-359704.raw.solitaire_city_journey`
WHERE log_date BETWEEN '2026-08-08' AND '2026-08-10'
  AND client_version >= 438
  AND event = '3120_TOURNAMENT_CREATE_FAIL'
GROUP BY error_code
ORDER BY cnt DESC;
