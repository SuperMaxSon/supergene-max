쿼리

테이블명 = 코드의 app 값 · mahjong / cozy_tiles / puzzle_block_master(=퍼블마) / solitaire_city_journey

생성 퍼널 + 거절률 (프로젝트 교체해서 사용) 
SELECT
  COUNTIF(event = '3100_TOURNAMENT_CREATE')         AS create_try,
  COUNTIF(event = '3110_TOURNAMENT_CREATE_SUCCESS') AS create_ok,
  ROUND(SAFE_DIVIDE(
    COUNTIF(event = '3120_TOURNAMENT_CREATE_FAIL'
            AND JSON_VALUE(data, '$.error_code') = 'USER_INPUT'),
    COUNTIF(event = '3100_TOURNAMENT_CREATE')) * 100, 1) AS reject_rate_pct
FROM `game-log-359704.raw.solitaire_city_journey`
WHERE log_date BETWEEN '2026-08-03' AND '2026-08-10'
  AND event IN ('3100_TOURNAMENT_CREATE','3110_TOURNAMENT_CREATE_SUCCESS',
                '3120_TOURNAMENT_CREATE_FAIL');
억제 효과 확인 (전후 비교) 
SELECT
  IF(log_date < '2026-08-07', 'before', 'after') AS phase,
  ROUND(SAFE_DIVIDE(
    COUNTIF(event = '3120_TOURNAMENT_CREATE_FAIL'
            AND JSON_VALUE(data, '$.error_code') = 'USER_INPUT'),
    COUNTIF(event = '3100_TOURNAMENT_CREATE')) * 100, 1) AS reject_rate_pct
FROM `game-log-359704.raw.solitaire_city_journey`
WHERE log_date BETWEEN '2026-08-03' AND '2026-08-10'
  AND event IN ('3100_TOURNAMENT_CREATE','3120_TOURNAMENT_CREATE_FAIL')
GROUP BY phase;
확인 범위 BigQuery 실측은 솔리테어·마종·코지·퍼블마(2026-08-03~08-10). 코드 실측은 5개 리포 main 브랜치. 가설 10번(성숙도)은 미검증입니다. 3120이 시도보다 약 5% 많아 로비 경로에 중복 기록이 있습니다(결론 영향 없음).
