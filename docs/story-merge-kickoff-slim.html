2. 판단 원칙 — 허브 자동 플레이 순서를 따른다

원칙왜 · 어떻게
보상은 빈칸이 있을 때만, 한 수에 하나보상함은 빈칸이 하나라도 있으면 첫 빈칸에 하나를 꺼낸다. 꺼낸 수는 그대로 이어서 다른 수를 고른다. 빈칸이 없으면 꺼내지 않는다.
심부름은 시트 비용이 모이면시트 cost_coin 만큼 코인이 모였을 때만 한다. 코인 1개마다 하면 보드를 거의 안 두고 레벨만 올라 판이 잠긴 채 찬다. 클라가 TEST 로 1코인만 떼는 동안은 봇이 덜 뗀 차액을 장부에 적어 가진 코인에서 뺀다 — 안 빼면 심부름만 연달아 한다.
납품이 합치기보다 먼저오더에 낼 수 있는 아이템이 있으면 합치기 전에 낸다.
재화 수확은 체인 끝에서만코인·젬은 체인 끝 단계만 수확한다(합칠수록 이득). 에너지도 체인 끝 단계(2905)까지 합친 뒤 수확한다 — 허브 페이지는 짝이 없으면 바로 거두지만 봇은 최고 단계까지 가져간다. 에너지가 모자라 생산이 멈췄을 때만 가장 높은 단계부터 먼저 거둔다(젬으로 사기 전).
합치기 → 상자 개봉 → 상자 털기 → 생성기한 칸도 안 늘리는 수부터, 칸을 쓰는 생산은 마지막이다. 봇은 순서를 조금 바꾼다 — 안 연 상자를 먼저 열고, 상자를 생성기보다 먼저 파괴될 때까지 쏟는다. 생산 전에는 보드를 정리한다(아래 표).
꽉 찼을 때만 칸을 판다빈칸 0일 때만 움직인다. 최고 단계 코인·젬 수확 → 가장 싼 아이템 판매. 판매 대상은 희귀 · 생성기 · 오더 요구품이 아닌 것이고, 방금 만든 아이템은 피하며 짝 없는 것부터 판다.
2초 넘게 쉬지 않는다이 게임은 늘 할 게 있는 게 정상이다. 기다려야 할 때도 2초마다 판을 다시 본다.

아래는 허브 자동 플레이 위에 얹은 규칙이다. 허브 페이지에 없고, 클라 봇만 따른다.

원칙왜 · 어떻게
상자가 먼저다 (순서 4)상자가 나오면 안 열었으면 먼저 연다(개봉은 칸을 안 쓴다). 그다음 쭉 쏟되, 합칠 수 있는 게 생기면 그때그때 합친다. 상자가 파괴될 때까지 쏟고, 상자 생산이 생성기 생산보다 먼저다. 쏟아 나온 재화 아이템은 바로 거두지 않고 끝 단계까지 합친다.
생산 전에 보드를 정리한다 (순서 4)상자나 생성기를 누르기 전 빈칸이 3칸 미만이면 짝 없는 아이템(오더 요구품 · 희귀 · 생성기 · 상자 · 도구 · 재화가 아닌 것)을 싼 것부터 판다. 체인 보호로 못 팔면 보관한다. 3칸 이상이면 바로 생산한다. 짝 있는 아이템은 팔지 않는다. 빈칸을 확보해 두고 연달아 생산·병합해야 흐름이 끊기지 않는다.
보관함 (순서 6)꽉 찼을 때 보관 → 아무거나 보관 → 젬으로 보관함 칸 구매. 체인 보호가 페이지는 팔 수 있는 아이템의 판매를 막기 때문에 클라에서만 필요하다.
에너지 구매 (순서 7)생성기 경로로 산다. 페이지는 에너지가 무한이라 이 수가 없다.
기다리기 (순서 8)수 사이에 최대 2초만 쉰다. 페이지는 게임 시계를 감아 넘기지만 클라는 실시간이다.

3. 한 수 고르는 순서

순서수조건 · 고르는 기준
0보상함 꺼내기빈칸 ≥ 1 · 보상 남아 있음. 한 수에 하나, 이어서 다음 수를 고른다
1심부름버튼이 켜져 있고 시트 비용만큼 코인이 모임
2오더 납품채워진 슬롯 중 번호가 낮은 것
3재화 수확코인·젬은 체인 끝 단계만. 에너지도 체인 끝 단계만(허브는 짝 없으면 바로 — 허브와 다름). 에너지 부족으로 생산이 막히면 가장 높은 단계부터
4상자 개봉 → 합치기 → 상자 쏟기 → 생성기 순서 · 정리는 허브와 다름안 연 상자가 있으면 먼저 연다. 합치기는 결과가 오더에 모자란 요구품 → 도착지가 거미줄 → 도착지 옆에 상자 → 나머지. 상자는 파괴될 때까지 쏟고 생성기보다 먼저. 상자 · 생성기 둘 다 빈칸 < 3 이면 먼저 짝 없는 아이템 판매 → 체인 보호면 보관. 생성기는 오더에 모자란 체인 → 재고 있음 → 거미줄 칸 체인
5(빈칸 0) 수확 → 판매최고 단계 코인·젬·에너지 수확 → 희귀 · 생성기 · 오더 요구품이 아닌 가장 싼 아이템 판매(방금 만든 것 회피 · 짝 없음 우선)
6(빈칸 0) 보관 · 칸 구매 클라 전용보관 → 아무거나 보관 → 젬으로 보관함 칸 구매. 체인 보호가 판매를 막을 때
7에너지 구매 클라 전용생성기 경로. 페이지는 에너지 무한
8기다리기최대 2초. 페이지는 시계를 감고, 클라는 실시간으로 2초마다 다시 본다
