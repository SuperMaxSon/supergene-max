2. 판단 원칙 — 칸 예산

원칙왜 · 어떻게
빈칸을 늘 남겨 둔다빈칸이 0이면 생산 · 상자 · 보상 · 가위가 모두 멈춘다. 새로 채우기 전에 칸을 차지하는 것부터 없앤다.
보상은 칸이 넉넉할 때 받는다보상함은 잃지 않으니 미뤄도 된다. 빈칸 3칸 이상 · 보드에 털 상자가 없을 때만 꺼낸다. 한두 칸 남았을 때 받으면 상자가 칸을 먹고 판이 막힌다.
상자를 받으면 먼저 턴다소모형 상자는 에너지 없이 자원을 주고, 다 쏟으면 사라져 칸이 빈다. 생성기보다 먼저 쏟는다.
빠듯하면 소비부터 (빈칸 ≤ 2)합치기 → 재화 아이템 수확(단계 무관) → 상자 개봉 시작 · 털기 → 판매가 0 버리기.
꽉 차면 칸을 만든다 (빈칸 0)보관함에 넣기 → 보관함이 차면 젬으로 칸 구매 → 그다음 판매. 넣을 게 없으면 가치를 안 따지고 넣는다(판매가 0 · 체인 보호 아이템 → 상자 순).
심부름은 시트 비용이 모이면코인 1개마다 심부름을 하면 보드를 거의 안 두고 레벨만 올라 판이 잠긴 채 찬다. 시트 cost_coin 만큼 모일 때까지 보드를 둔다.
2초 넘게 쉬지 않는다이 게임은 늘 할 게 있는 게 정상이다. 기다려야 할 때도 2초마다 판을 다시 본다.
