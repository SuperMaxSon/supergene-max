💡
왜 필요한가 이미지를 여러 장 선택해도 2.4 의 Inspector 는 한 장만 보여줍니다. packable 이나 trimType 을 수백 장에 걸려면 한 장씩 열어야 하고, 3.x 에도 배치 편집기는 없습니다. 유니티 인스펙터의 다중 선택 편집을 2.4 로 옮겨온 것입니다.

설치

macOS

  1. zip 을 풀고 폴더를 엽니다.
  2. install_mac.command 를 오른쪽 클릭 → 열기 → 다시 열기.
    처음 한 번만 필요합니다. 두 번째부터는 더블클릭으로 열립니다.
  3. 「설치 완료」가 뜨면 아무 키나 누르고, 창은 ⌘ W 로 닫습니다.
  4. Cocos Creator 를 완전히 종료한 뒤 다시 실행합니다.

Windows

  1. 받은 zip 을 오른쪽 클릭 → 속성 → [차단 해제] 체크 → 확인, 그 다음 압축을 풉니다.
  2. install_win.bat 을 더블클릭합니다. 「Windows의 PC 보호」가 뜨면 추가 정보 → 실행.
  3. [OK] installed 가 뜨면 아무 키나 눌러 닫습니다.
  4. Cocos Creator 를 완전히 종료한 뒤 다시 실행합니다.
✅
설치가 됐는지 확인 에디터를 다시 켰을 때 Console 에 [sprite-batch] package loaded 가 찍히면 정상입니다.
⚠️
Windows 설치기 메시지는 영어입니다 cmd 콘솔에서 한글이 깨지는 걸 피하려고 .bat 안내만 영어로 뒀습니다. 자주 나오는 두 가지는 [ERROR] running from a temporary folder(zip 안에서 바로 실행한 것 — 압축을 실제 폴더에 풀고 다시 실행)와 [ERROR] copy failed(Cocos Creator 가 켜져 있음 — 종료 후 재실행)입니다.

쓰는 법

  1. Assets 패널에서 이미지를 여러 장 선택합니다. 범위는 Shift, 하나씩은 ⌘(Windows 는 Ctrl). 폴더를 골라도 됩니다.
  2. ⌘ ⇧ S (Windows 는 Ctrl ⇧ S) — 또는 상단 메뉴 Sprite Batch → Open
  3. 바꾸고 싶은 항목만 건드리고 Apply 를 누릅니다.

바꿀 수 있는 항목

층 항목
Texture type · wrapMode · filterMode · premultiplyAlpha · genMipmaps · packable
Sprite Frame trimType · trimThreshold — 하위 프레임 전체에 적용
Platform Settings 다른 에셋에서 복사 · 비우기 · JSON 그대로 붙여넣기

알아둘 규칙 세 가지

  1. 건드린 항목만 기록됩니다. packable 만 바꾸면 trimType 등 나머지는 이미지마다 원래 값 그대로 남습니다.
  2. 값이 서로 다른 항목은 - 로 표시됩니다(유니티의 혼합값). 그대로 두면 적용에서 빠지고, 값을 고르는 순간 선택한 전부에 그 값이 들어갑니다. 지금 무엇을 바꾸는 중인지는 주황색 하이라이트와 was <원래값> 으로 보입니다.
  3. 압축 설정은 직접 입력하지 않고 복사해서 씁니다. 이미지 한 장을 기본 Inspector 에서 원하는 대로 맞춘 뒤, 그 장을 포함해 여러 장을 선택하고 copy from… 에서 고르면 나머지 전부에 같은 압축 설정이 들어갑니다.
🚨
적용 전에 알아둘 것 바뀌는 것은 각 이미지의 .meta 파일입니다. 즉 그만큼 git diff 가 생깁니다. 되돌리기 편하도록 작업 전 워킹트리를 깨끗하게 두는 걸 권합니다. 50장 이상을 한 번에 바꿀 때는 실수 방지로 Apply 를 두 번 눌러야 실행되고, type 변경은 스프라이트 프레임을 없애기 때문에 그 프레임을 참조하던 프리팹이 깨질 수 있습니다(패널에 경고가 뜹니다).

안 될 때

동작이 이상합니다 — probe 로 진단

패널 오른쪽 아래 probe 를 누르면 Console 에 진단 정보(선택된 에셋 수, 인식된 경로, 사용 가능한 API 목록)가 찍힙니다. 그 내용을 그대로 스레드에 붙여 주시면 원인 파악이 빠릅니다.

설치기가 실행되지 않습니다 (회사 PC 정책 · 백신)

설치기가 하는 일은 sprite-batch 폴더를 전역 packages 폴더에 복사하는 것뿐입니다. 아래 방법은 결과가 완전히 같습니다.

방법 1 — 명령 한 줄 (Windows)

압축 푼 폴더를 탐색기에서 열고, 주소창에 cmd 를 입력해 Enter. 열린 창에 아래를 붙여넣습니다. 

xcopy /E /I /Y sprite-batch "%USERPROFILE%\.CocosCreator\packages\sprite-batch\"

방법 2 — 직접 복사 (공통)

아래 폴더로 이동해(없으면 새로 만들고) sprite-batch 폴더를 통째로 넣습니다.

macOS     ~/.CocosCreator/packages          (Finder 에서 ⌘ ⇧ G)
Windows   %USERPROFILE%\.CocosCreator\packages
설치했는데 Console 에 아무것도 안 찍힙니다

폴더가 두 겹으로 들어간 경우가 대부분입니다. 최종 모양이 이래야 합니다.

~/.CocosCreator/packages/sprite-batch/package.json

packages/sprite-batch/sprite-batch/… 처럼 이름이 두 번 겹치면 에디터가 확장으로 인식하지 못합니다.

새 버전이 이상합니다 · 지우고 싶습니다

설치기는 기존 설치본을 지우지 않고 sprite-batch.bak 으로 옮겨 둡니다. 새 버전이 이상하면 .bak 의 이름을 되돌려 그대로 쓰면 됩니다.

완전히 지우려면 같은 폴더의 uninstall_mac.command · uninstall_win.bat 을 실행합니다. 확장과 .bak 을 함께 지웁니다. (정말 지울지 한 번 물어보므로 y 를 입력해야 삭제됩니다. Cocos 는 닫고 진행하세요.)

확인 범위 macOS 에서 설치 · 실행 확인. Windows 설치기는 mac 에서 작성했고 윈도우 실기 실행은 아직 검증되지 않았습니다 — 첫 설치자는 결과를 스레드에 남겨 주세요.
