② 확인된 열세는 하나 — 첫 판 완료율 46.5% vs 54.3%

③ 원인 추적 — 첫 판이 마종의 2배 길다 (13탭 vs 8탭)

마종 첫 판 TT_001은 8타일 / 4매칭 = 8탭이고, 솔리테어 TUT_0001은 13장 A→K 체인 = 13탭입니다. 난이도는 오히려 우리가 관대합니다 — 튜토 티어 deck_help_rate / field_help_rate = 10000이라 뽑는 카드가 100% 매칭 가능하고, 덱을 소진해도 실패 팝업이 없습니다. 즉 어려워서가 아니라 길어서입니다. 우리 판 길이 자체는 강점입니다 (25~60초 · 벤치 1.5~3분) — 첫 판만 예외적으로 깁니다.

여기까지가 원인 추적이고, 개선안은 아직 아닙니다. 이 인과가 성립하려면 아래 세 개가 먼저 해소돼야 합니다 — (1) −7.8pt가 유입 품질 차이가 아니라는 확인(오가닉 대조), (2) "8탭이라서 완료율이 높다"는 것은 지금 상관이며 인과가 아님, (3) 첫 판을 줄이면 튜토리얼 구간 이탈(우리가 우위인 항목)을 깎을 위험. 셋 다 열려 있는 항목에 올려 뒀습니다.

전제 조건 — 유입량이 25배 다르다

① NRU 분당 생존 곡선 (0~10분) — SQL 펼치기 
DECLARE d_from DATE DEFAULT DATE '2026-08-01';
DECLARE d_to   DATE DEFAULT DATE '2026-08-13';

WITH s AS (
  SELECT
    CONCAT(CAST(player_id AS STRING), '_', CAST(logincount_total AS STRING)) AS session_key,
    TIMESTAMP_DIFF(TIMESTAMP(MAX(log_time)), TIMESTAMP(MIN(log_time)), SECOND) AS dur_sec
  FROM `game-log-359704.raw.TABLE_NAME`
  WHERE log_date BETWEEN d_from AND d_to
    AND logincount_total = 1
    AND (is_dev = FALSE OR is_dev IS NULL)
    AND player_id > 0
  GROUP BY session_key
)
SELECT
  m AS `경과분`,
  COUNT(DISTINCT CASE WHEN dur_sec >= m * 60 THEN session_key END) AS `생존세션`,
  ROUND(
    COUNT(DISTINCT CASE WHEN dur_sec >= m * 60 THEN session_key END) * 100.0
    / COUNT(DISTINCT session_key), 2
  ) AS `생존율_pct`
FROM s, UNNEST(GENERATE_ARRAY(0, 10)) AS m
GROUP BY m
ORDER BY m

DECLARE d_from DATE DEFAULT DATE '2026-08-01';
DECLARE d_to   DATE DEFAULT DATE '2026-08-13';

WITH nru AS (
  SELECT player_id, MIN(log_date) AS d0
  FROM `game-log-359704.raw.TABLE_NAME`
  WHERE log_date BETWEEN d_from AND DATE_ADD(d_to, INTERVAL 1 DAY)
    AND logincount_total = 1
    AND (is_dev = FALSE OR is_dev IS NULL)
    AND player_id > 0
  GROUP BY player_id

ret AS (
  SELECT DISTINCT t.player_id
  FROM `game-log-359704.raw.TABLE_NAME` t
  JOIN nru n ON t.player_id = n.player_id
  WHERE t.log_date = DATE_ADD(n.d0, INTERVAL 1 DAY)
)
SELECT
  COUNT(DISTINCT n.player_id) AS `NRU`,
  COUNT(DISTINCT r.player_id) AS `D1_복귀`,
  ROUND(COUNT(DISTINCT r.player_id) * 100.0 / COUNT(DISTINCT n.player_id), 2)
    AS `D1_retention_pct`
FROM nru n
LEFT JOIN ret r ON n.player_id = r.player_id
WHERE n.d0 <= d_to
