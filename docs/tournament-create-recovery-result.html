A network error has occurred · Request failed to be processed는 여전히 되살리기를 타지 않습니다. 문구가 바뀔 때마다 같은 이슈가 다시 올라오는 구조라서, 문구 비교를 없애고 NETWORK_FAILURE 코드만으로 판정하는 안을 검토 중입니다. 되살리기 여부는 문구가 아니라 random_key 일치로 확인하므로 오탐 위험은 사실상 없습니다.

앞으로 볼 지표 하나

3120 중 error_code = NETWORK_FAILURE 이면서 recover = 'skip'인 건수. 0이면 정상, 늘어나면 새 문구 변형이 생긴 것입니다. 이 계측은 이번 수정에서 함께 붙었습니다.

확인 범위 position = game_clear(클리어 자동 생성) 기준입니다. 로비 생성 경로는 되살아난 건과 정상 건을 구분하는 표시가 없어 이 문서에서 제외했습니다(표본 9건). 문구별 표는 빌드 450, 08-13 ~ 08-18 구간이며 지면 필터 없이 집계했습니다.
