이 도식을 읽는 법

같은 열의 서로 다른 행은 같은 구간에서 같이 받는 것이다(예: 영상 재생 중에 채팅 · 마을 · 데이터를 미리 받는다). 구간은 왼쪽에서 오른쪽으로 진행한다. 맨 아래 막대는 구간이 끝났을 때의 누적이다 — 연한 부분은 앞 구간까지, 진한 부분은 그 구간이 얹은 양이고, 점선이 목표 60MB(클라 성능 기준)다. 넘으면 붉게 칠한다. 마지막 열은 첫 입력 뒤에 이어지는 화면 전환을 앞 누적 위에 합산한 시나리오 추정이다(앞에서 놓은 손님 캐릭터는 뺐다).

놓는 것 첫 입력 뒤 · 메모리가 줄어드는 곳

  • 인게임을 떠날 때손님 캐릭터 · 후보 전원▼ 18.0MB
    메모리23.0MB▼18.0
    마을로 나갈 때마다 놓는다. 인게임에 다시 들어오면 다시 올린다(다운로드는 캐시, 디코딩만). 막대는 RU가 첫 입력 뒤 끝까지 쌓은 41.0MB에서 뺀 값이다.
  • 채팅이 끝날 때말풍선 · 이름박스 8장수치 미산출
    채팅 풀 프리팹도 같은 8장을 쥐고 있어서, 풀이 살아 있는 동안 실제 메모리는 거의 내려가지 않을 것이다(참조만 놓는다).
  • 채팅 줄이 사라질 때감정 클립수치 미산출
  • 택1 꾸미기를 고른 뒤안 고른 변형 텍스처수치 미산출
  • 놓지 않는 것아이템 이미지에리어 번들
    앱이 사는 동안 메모리에 상주한다. 아이템 이미지는 아웃게임도 같은 그림을 써서 놓지 않기로 했다.
