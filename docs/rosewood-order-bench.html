뽑기 분포

같은 조건으로 여러 장을 연속 발급해서 실제로 어떤 오더가 나오는지를 봅니다. 고정 오더는 빼고 랜덤 경로만 돌립니다. 보드가 비어 있으면 모든 후보가 「미요구」 배수 1000 을 받아 평평하게 나오고, 보드에 물건이 쌓이면 「동급·하급 보유」 배수 10000 이 걸려 쏠립니다.
