오더 생성 벤치

Rosewood 코어루프를 직접 눌러 보는 페이지입니다. 생성기로 뽑고, 합치고, 오더에 납품합니다. 개발 기획서 1.2.1 오더 생성의 8단계 판정 근거와 뽑기 분포는 오더 추첨 분석 페이지에서 봅니다 — 같은 엔진 파일(js/rosewood-order-engine.js)을 읽어 여기와 똑같이 판정합니다. 밸런스 데이터는 연출 값 섹션의 밸런스 JSON 버튼으로 통째로 갈아끼울 수 있고 다음 발급부터 바로 먹습니다. 아이템·체인·규칙 테이블은 밸런스 시트 실물입니다 — 236종 30체인이 시트에 적힌 이름 그대로 나옵니다. 아이템 아트 158장이 들어와 있어 칩에 실제 그림이 뜹니다 — 아직 안 온 일곱 체인(공구·차·찻잔·빵·꽃·수건·꿀)은 이름 글자로 그립니다. 그림을 감싼 색은 클러스터(공방·부엌·정원…), 테두리 무늬는 그 안의 체인이고 생성기 체인은 링이 하나 더 있습니다. 이름은 칩에 커서를 올리면 뜹니다.

칩을 끌어서 합치고, ⚡생성기를 눌러 생산합니다(재고 → 빈칸 → 에너지 → 산출 추첨 순서로 판정하고 나선의 첫 빈 칸에 놓습니다). 생성기는 체인의 1단계가 아니라 중간 단계부터 여럿이고, 자기 체인이 아니라 다른 체인을 낳습니다 — 공구함은 공구·페인트를, 벌통은 꿀·밀랍을 냅니다. 배지는 문서의 셀 배지 슬롯을 따릅니다 — A 좌상 재고 · B 우상 ⚡생성기 또는 ✓오더 요구 · C 우하 ♦최고 단계. 경험치 공급원은 심부름 하나뿐이라, 랜덤 오더를 보려면 심부름 완료로 레벨을 올려야 합니다 — Lv1 에 열리는 칸은 고정 오더 한 칸뿐이고 일반·손님은 Lv3, 스페셜 Lv4, 이벤트는 Lv6 부터입니다. 생산·병합·거부·납품 연출은 허브 머지 피드백 애니메이션 문서의 타이밍·이징을 그대로 씁니다 — A1 클릭 · A2 베지어 비행 · A4 흡수→임팩트→팝 · C1 거부 · C3 충전 완료 · C4 납품.
