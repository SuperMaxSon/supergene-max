발급 기록

연출 값

값을 고치는 곳은 여기가 아니라 허브 머지 피드백 애니메이션 문서입니다. 거기서 맞춘 값을 아래에 붙여 넣고 적용을 누르면 그 다음 연출부터 바로 먹습니다. 키는 벤치 키(PICK_SEC)와 엔진 상수명(MERGE_PICKUP_DURATION_SEC) 둘 다 받습니다 — 애니메이션 문서가 쓰는 cfg 이름을 그대로 넣어도 됩니다.

애니메이션 문서에서 맞춘 값을 붙여 넣고 적용을 누르세요.

밸런스 표는 여기서 통째로 갈아끼웁니다 — 형식이 깨지면 적용을 거절합니다

뽑기 분포

같은 조건으로 여러 장을 연속 발급해서 실제로 어떤 오더가 나오는지를 봅니다. 고정 오더는 빼고 랜덤 경로만 돌립니다. 보드가 비어 있으면 모든 후보가 「미요구」 배수 1000 을 받아 평평하게 나오고, 보드에 물건이 쌓이면 「동급·하급 보유」 배수 10000 이 걸려 쏠립니다. 보드 상황을 바꿔도 결과가 그대로면 보드에 셀 것이 없다는 뜻입니다 — 생성기는 세지 않으므로, 생성기만 놓인 보드는 빈 보드와 같습니다. 아래 줄에 실제로 무엇이 걸렸는지 적힙니다. 난수는 게임 진행과 분리된 별도 열을 쓰고 돌릴 때마다 이어집니다. 같은 그림을 다시 보려면 시드 고정을 켭니다. 레일 맥락을 켜면 지금 레일에 선 다른 오더의 요구와 슬롯 1 의 직전 요구가 그대로 들어가고, 반복 억제 카운터도 시뮬 안에서 감쇠·리셋하며 돌아갑니다 — 끄면 배수 4 개 중 「타 오더 요구」 축 둘이 나오지 않습니다.
