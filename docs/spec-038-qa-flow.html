SPEC-038 토너 초대 토글 — QA 가이드

토너 판을 깰 때마다 공유 다이얼로그만 뜨던 것을, 초대 → 공유 → 초대 → 공유 로 번갈아 뜨게 바꿨습니다.

솔리테어 · FB 인스턴트 dev 빌드 2026-08-13 개정

판정 흐름도 판을 깬 순간 위에서부터 순서대로 걸러집니다

"안 뜨는 게 정상"인 갈래가 둘 있습니다

신규 유저와 60초 이내 재클리어는 공유·초대 어느 쪽도 뜨지 않는 것이 정상입니다. 다이얼로그가 안 떴다고 바로 이슈로 올리기 전에 이 두 가지부터 확인해 주세요. 반대로 기능이 꺼져 있을 때(시트 0)와 이미 종료된 토너먼트에서는 예전처럼 공유가 반드시 떠야 합니다.

준비

항목 내용
빌드 FB 인스턴트 dev 빌드 (에디터 프리뷰에서는 토너 기능이 동작하지 않습니다)
실행 방법 아이콘 · 토너 링크 어느 쪽이든 됩니다. 아이콘으로 켠 뒤 로비에서 토너먼트에 참가해도 동일하게 동작합니다
차례 확인 · 변경 브라우저 콘솔에서 아래 명령 (다음 차례를 초대/공유로 강제 지정)
콘솔 명령 펼치기 
// 지금 차례 확인
// true = 다음은 초대 / false = 다음은 공유 / null = 아직 한 번도 안 뜬 상태(다음은 초대)
localStorage.getItem("tournamentInviteNext");

// 다음 차례를 "초대"로 지정
localStorage.setItem("tournamentInviteNext", "true");
location.reload();

// 다음 차례를 "공유"로 지정하려면 "true" 자리에 "false"
페이스북 플레이어 데이터가 아니라 브라우저 저장소입니다

이 값은 브라우저 localStorage에 저장됩니다. FBInstant.player.getDataAsync로 찾으면 나오지 않습니다. 시크릿 모드처럼 localStorage가 막힌 환경에서만 페이스북 저장소 안에 묶여 들어가고, 그때는 위 명령이 동작하지 않으니 일반 창에서 테스트해 주세요. 또 기기나 브라우저가 바뀌면 차례가 초기화되어 초대부터 다시 시작하는데, 이것도 정상 동작입니다.

A. 기본 동작 진행 중인 토너먼트에 들어간 뒤, 위에서부터 끊지 말고 순서대로

순서 이렇게 하면 이래야 정상
A-1 차례를 초대로 지정하고 판 클리어 초대 다이얼로그가 뜬다 → 전송
A-2 곧바로(60초 안) 한 판 더 클리어 아무것도 안 뜬다
A-3 60초 지난 뒤 한 판 더 클리어 공유 다이얼로그가 뜬다 (차례가 넘어갔으므로)
A-4 60초 지난 뒤 클리어 → 초대창을 그냥 닫기 초대 다이얼로그가 떴다가 닫힌다
A-5 60초 지난 뒤 한 판 더 클리어 공유가 뜬다 (취소해도 차례는 넘어감)
A-6 앱을 완전히 껐다 켜고 60초 뒤 클리어 껐을 때의 차례가 그대로 이어진다 (초기화되지 않음)
A-2와 A-5가 이 기능의 핵심

A-2는 60초 안에 또 뜨지 않는지, A-5는 초대를 취소해도 다음 판이 공유로 넘어가는지를 봅니다. 둘 중 하나라도 어긋나면 바로 이슈로 올려 주세요.

B. 안 떠야 하는 경우 각각 따로 실행

순서 이렇게 하면 이래야 정상
B-1 이미 끝난 토너먼트 컨텍스트에서 판 클리어 항상 공유만 뜬다. 초대는 절대 안 뜬다
B-2 새 계정(튜토리얼 미완료)으로 토너 판 3번 클리어 세 번 모두 아무것도 안 뜬다
B-3 기능을 끈 상태(개발자에게 요청)로 토너 판 클리어 예전처럼 공유만 뜬다. 60초 제한도 없다
B-3이 제일 중요합니다

문제가 생겼을 때 되돌리는 유일한 방법이 기능 끄기입니다. 껐을 때 예전 동작으로 완전히 돌아가지 않으면 라이브에서 되돌릴 수단이 없습니다. 개발자에게 요청해서 한 번은 꼭 확인해 주세요.

C. 기존 기능이 그대로인지 이번에 건드리지 않았지만 옆에 있는 것들

순서 이렇게 하면 이래야 정상
C-1 일반(비토너) 판 클리어 기존 토너 만들기 다이얼로그가 그대로 뜬다
C-2 토너 판을 중간에 나가기 아무것도 안 뜨고, 다음 판 차례도 그대로다
C-3 레벨 진입 · 우편함 · 레벨 완료 화면에서 친구 초대 초대가 기존대로 정상 동작한다
C-4 B-2(신규 계정, 아무것도 안 뜸) 상태에서 클리어 후 토너 순위 확인 다이얼로그가 안 떠도 내 점수는 올라가 있어야 한다
C-4를 빠뜨리지 마세요

다이얼로그를 막는 처리와 점수를 서버에 올리는 처리가 붙어 있어서, 잘못 만들면 "팝업이 안 뜨는 판은 점수도 안 올라가는" 문제가 생깁니다. 눈에 잘 안 띄는 대신 영향이 가장 큰 항목입니다.

기획서와 다른 점 아래 3가지는 의도된 차이입니다 — 결함이 아닙니다

기획서 문구와 실제 구현이 어긋나는 부분은 이미 라이브에서 돌고 있는 퍼블리싱 마스터 쪽에 맞췄습니다. 기획서만 보고 테스트하면 아래가 어긋난 것처럼 보입니다.

  • 첫 차례가 공유가 아니라 초대입니다
  • 초대창을 취소해도 차례는 넘어갑니다 (A-4 · A-5)
  • 신규 계정은 공유·초대 어느 쪽도 안 뜹니다 (B-2)
이 3가지는 이슈로 올리지 말아 주세요

반대로 여기에 없는 기획서 불일치를 발견하면 올려 주세요 — 의도한 차이가 아닐 수 있습니다.

이건 버그입니다

증상 어긋난 항목
초대만 계속 뜨고 공유가 한 번도 안 뜬다 A-3 · A-5 (차례가 안 넘어감)
클리어할 때마다 매번 다이얼로그가 뜬다 A-2 (60초 제한이 안 걸림)
이미 끝난 토너먼트에서 초대가 뜬다 B-1 (적용 범위를 벗어남)
기능을 껐는데도 초대가 뜨거나 공유가 안 뜬다 B-3 (되돌리기 불가 — 최우선)
다이얼로그가 안 뜬 판의 토너 점수가 안 올라간다 C-4 (최우선)
앱을 껐다 켜면 항상 초대부터 다시 시작한다 A-6 (차례가 저장 안 됨)
참고 초대 이미지와 문구는 기존 친구 초대와 같은 것을 씁니다 — 새 이미지가 아니어도 정상입니다. 미검증 이 문서의 항목은 아직 실제 기기에서 한 번도 실행되지 않았습니다.
